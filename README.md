# longview_FUTURES

This repository contains the code and associated files for running FUTURES as part of the project, "The Long View: Development of a 500-year climate adaptation planning framework with the Eastern Band of Cherokee Indians"

code_outline uses the FUTURES tutorial (https://grasswiki.osgeo.org/wiki/FUTURES_tutorial#Software) as an outline with comments pointing out where data, parameters, and scenarios will need to be modified for this project.
